# CO2 People Counter

A project for estimating the number of people in a room based on
CO2 concentration and ventilation rate.

## Project goal

The goal is to investigate whether the number of people in a room
can be estimated from CO2 measurements using linear regression.

## Hardware

- CO2 sensor
- Air conditioning unit
- Computer for data analysis

## Data

The `data/` directory contains the CO2 measurements collected
during the experiments.

## Model

The project uses scikit-learn to train a linear regression model.
